Free and open source tool for Odoo developers and consultants to analyze
and understand QWeb reports. **No license key or external server required.**

**Key Features**
----------------

✓ **Complete Analysis**: Detect base views, inherited views, t-calls, and sibling views

✓ **Dependency Tree**: Visual hierarchy of all view relationships

✓ **XPath Detection**: See exactly where each modification happens

✓ **Module Tracking**: Know which module each view comes from

✓ **One-Click Export**: Download comprehensive analysis as a .txt file

✓ **Fully Local**: Analysis runs entirely inside Odoo — no internet needed

**Usage**
---------

1. Go to **Settings > Technical > Reporting > Reports**
2. Select any report from the list
3. Click **Action > Analyze Report Views**
4. A ``.txt`` file downloads automatically with the complete analysis

**Compatibility**
-----------------

* Odoo 14.0, 15.0, 16.0, 17.0, 18.0, 19.0
